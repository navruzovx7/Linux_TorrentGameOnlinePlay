Contributing to Lunix 60Hz Fix Guide

Thank you for your interest in improving this guide. Please follow these rules to keep the repository clear and useful.

What to include in a PR
- Describe the issue or improvement in the PR description.
- If you add a fix, include: commands you ran, exact config snippets, and the validation outputs.
- Add images to `images/` with recommended names (see images/README.md).

Commit message format
- Use: `Lunix 60Hz fix: short description`

Branching & PRs
- For non-trivial changes, create a branch `fix/<short-description>` and open a PR against `main`.

Code of conduct
- Be respectful and constructive.
